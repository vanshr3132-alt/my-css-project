# Museum of Candy

A responsive, single-page landing site for a fictional candy museum, built with HTML, CSS, Bootstrap 4, and a little jQuery.

**Live demo:** 
https://vanshr3132-alt.github.io/my-css-project/

https://github.com/vanshr3132-alt/my-css-project/blob/main/museumofcandyss.png

## Features
- Fixed navigation bar that collapses into a hamburger menu on small screens
- Navbar background changes after you scroll (jQuery scroll listener)
- Large repeating hero heading that appears only on large screens
- Alternating image and text sections that stack and reorder on mobile
- Custom colors and the Nunito font from Google Fonts
- Layout adjusts at breakpoints, including a custom media query at 1200px

## Tech Stack
HTML5, CSS3, Bootstrap 4.1.3 (grid and navbar), jQuery, Google Fonts (Nunito)

## What I Practiced
- Building layouts with Bootstrap's responsive grid (`col-md-6`, `order-*`, `d-none d-lg-block`)
- Writing custom CSS on top of a framework
- Using media queries for responsive font sizes
- Toggling a CSS class with JavaScript on scroll
- Deploying a static site with GitHub Pages
